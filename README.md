# RPCS3

**RPCS3** is the PS3 emulator for Windows, Linux, macOS and FreeBSD. rpcs3 emulator, rpcs3 pc, rpcs3 firmware, rpcs3 games, god of war 3 rpcs3. Vulkan + LLVM. Landmark v0.0.42. Rolling builds from rpcs3.net/download.

## Getting Started
1. Download the zip.
2. Extract on Windows 10/11.
3. Install PS3 firmware through File - Install Firmware.
4. Notes in `files/notes/`.

## FAQ

**Stable build?**
No. Rolling release. Landmark tag is v0.0.42. Grab the latest from the official download page.

**Firmware?**
Dump from a PS3 you own. Zip has no firmware.

## Requirements
Windows 10/11 64-bit. Vulkan GPU. VC++ 2015-2022 runtime.
